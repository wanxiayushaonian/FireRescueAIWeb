# 熟悉考核 agent 配置:教练闭环 + 薄弱画像上下文(B 方案)

> 日期:2026-08-17 | 目标:在 uagent 平台创建「熟悉考核·教练」应用,激活模块三的教练闭环。
> 数据通道已按用户拍板走 **B 方案**:前端在每次发送的消息前注入 `[系统上下文]` 块
> (最近考核成绩/薄弱点位/低熟悉度点位),agent 直接读上下文,**无需 MCP 工具查成绩**。
> 代码已上线:`src/lib/agent-context.ts`(注入函数)+ AgentSidebar/AgentChatThread 接线

## 一、模块定位

**标志性能力 = 教练闭环**:看到薄弱画像 → 针对性出题/讲解 → 引导实地强化(联动六熟悉导览)。
不是题库解析器——答错不是终点,是把学员带回现场。

## 二、平台配置步骤

1. uagent 平台新建应用「熟悉考核·教练」,发布后拿 app_id,以 `NEXT_PUBLIC_TRAINING_APP_ID`
   注入(代码接线同 objects 模式,目前 training 业务助手回退通用 app;拿到 id 后改
   `lib/agent-app-ids.ts` 的 training 键或加环境变量注入)。
2. mcp_servers 挂 firerescue-business(8787),勾选:
   - `query_knowledge`(预案知识佐证讲解)
   - `fly_to` / `focus_floors` / `list_floors`(3D 联动:讲解点位时把学员带过去)
3. **不勾选**:成绩类工具(无——B 方案不需要)、业务档案三查(对象总览域)、GIS/调派/推演工具。
4. 贴入下方提示词。

## 三、上下文注入说明(发给 agent 的每条消息自动携带)

```
[系统上下文|界面状态,非用户输入,不要复述] 3D场景=…;最近考核=战斗员/72分/总20题/错3题;
薄弱点位=避难层[13F]错3、室内消火栓[B1]错1;低熟悉度=…[/系统上下文]
<用户消息>
```

- 无考核记录时:`考核记录=无(用户尚未考核,可引导先做一轮)`。
- 上下文是**快照**:熟悉度/成绩会随用户操作变化,每次发送都会刷新。

## 四、提示词(全文复制)

```markdown
# 角色
你是九江市消防救援「熟悉考核」模块的消防业务教练,服务消防员的六熟悉训练
(熟悉重点单位/责任区/处置对策/建筑重点部位/消防设施/消防组织分工)。
你的核心职责不是讲解题库,而是**教练闭环**:发现薄弱 → 针对性训练 → 带到现场强化。

# 能力边界
- 你负责:薄弱画像分析、针对性出题与讲解、考核答疑、引导实地熟悉(3D 联动)。
- 建筑档案细节/作战战术属「对象总览」助手;考核系统操作问题引导用户使用界面考核入口。
- 消息开头的 [系统上下文] 块是界面状态注入(考核成绩/薄弱点位),**不要复述给用户,
  直接作为训练依据使用**。

# 教练闭环(核心工作流)
1. **画像优先**:对话开始时若上下文含薄弱点位/低熟悉度,主动提出针对性训练计划
   (如"你上次避难层相关错了 3 题,我们先过一遍 13F/25F 避难层?")。
2. **针对性训练**:围绕薄弱点位出 3-5 道小题(选择/简答混合),逐题反馈,错题讲透
   (位置/作用/记忆锚点)。出题后等用户作答,不要自问自答。
3. **实地强化**:讲完一个点位后用 3D 工具带学员去现场——list_floors 拿楼层 id →
   focus_floors 聚焦该层,说"现在带你到 13F 避难层,注意…"(一次回答最多 1 次 3D 联动)。
4. **收尾**:训练结束总结薄弱项改善情况,建议下次考核时间。
5. 需要预案知识佐证时 query_knowledge,引用注明来源文档。

# 答题讲解规范
- 判题明确(对/错 + 关键点),不模棱两可。
- 错题讲解结构:正确答案 → 为什么(规范/原理) → 记忆锚点(楼层/位置/数量)。
- 涉及"金茂大厦"的旧表述一律用"乐盈广场21号楼"(40F+B1)。

# 风格
- 教练口吻:严格但鼓励;先诊断后训练,不盲目刷题。
- 单次回复 250 字上下;出题时一题一条消息,等作答。
```

## 五、验证场景(配好后熟悉考核页 AgentSidebar 实测)

| 问句/操作 | 预期 |
|---|---|
| 先做一轮考核(答错几题) → 对话「帮我练练」 | agent 引用上下文薄弱点位,出针对性题 |
| 「避难层有什么讲究?」 | 讲解 + focus_floors 带到避难层 |
| 新会话无考核记录 | 引导先做一轮考核,不出题 |
| 答错一题 | 对/错 + 正解 + 原理 + 记忆锚点 |

## 六、六熟悉 AI 引导接管(模块三一级界面,ref 优先级 #1)

TrainingView 左面板「AI 引导·六熟悉」目前是**声明式步进 + 演示 narration**;接入教练 agent 后,
narration 由 agent 实时生成,引导节奏(下一步去哪/看什么/考什么)由 agent 主导。
**代码侧已就绪**(六熟悉步的「问智能体」按钮走 onRequestAgentHint);配好 app 即生效。

- 上下文注入已含薄弱画像(training 段),agent 可在引导中**优先带学员去薄弱楼层**。
- 六熟悉章节与楼层实况:周边交通水源 → 责任区单位 → 处置对策 → 建筑重点部位(B1/1F/16F/
  38-40F 炸开)→ 内部消防设施 → 消防组织分工;避难层实为 13F/25F(题库已校对)。
- 引导步进由前端驱动(章节完成回写熟悉度),agent 不改变进度——**agent 负责"讲 + 带看 + 随考",
  进度与熟悉度仍走前端存储**。

# 态势总览增强与 Agent 智能化路线图

> 基于 2026-08-07 讨论,梳理态势总览模块(RealGisMap)的增强方向与 agent 智能化路径,按优先级排期。
> 原则:不堆功能,围绕"消防指挥实战场景" + "为 agent 智能化铺路"两条主线。

---

## 一、现状基础(已具备)

- **底图**:高德矢量/卫星(GCJ02,Leaflet)+ 图层显隐
- **点位图层**:消防站 / 水源 / 市·区县边界 / 重点单位 / 重点建筑 / 重点区域
- **右键圆环菜单**:单位/建筑(派遣/修正/详情)、消防站(定位/详情/力量明细)
- **多站派遣**:多消防站到场路线(高德 driving + 各 ETA + 呼吸动效 + 折叠面板)
- **工具**:`Ctrl+K` 命令面板(地址查询/单位跳转/动作)+ 坐标修正(地址/拾取/手动)
- **数据联动**:消防站 popup 动态人员数、力量明细面板、执勤力量资源面板
- **场景总线**:sceneLog(`addSceneAction`/`subscribeSceneLog`),`showRoute` 已接渲染通道
- **Agent 基础**:AgentChat 组件已有;`plan_dispatch` MCP 通道已预留(showRoute scene action)

---

## 二、增强方向(4 层)

### 第 1 层:数据 / 信息补全 — 让地图"信息更全"

| 增强项 | 价值 | 数据源 |
|---|---|---|
| **警情/事件图层** | 指挥核心 — 实时警情点位 + 状态(接警/出动/到场/控制/结束) | 新建 incidents 表 + 接警系统对接 |
| **消防站状态色** | 在位/出警中/离线(图标色区分) | fire_force_items 聚合 + 状态 |
| **重点单位风险等级** | 高层/化工/人员密集 — 图标/颜色区分 | key_units extra_attrs 扩展 risk_level |
| **天气风向** | 消防指挥关键(风向影响蔓延方向/部署) | 高德天气 API |
| **水源状态** | 可用/维修/水压 | water_sources 状态字段 |

### 第 2 层:信息联动 — 选目标 → 关联自动呈现

- **点重点单位 → 自动联动**:周边 X 米水源高亮(半径查询已有 `haversineKm`)+ 派遣面板 + 风险摘要 — 一键展开全部决策信息
- **警情接入 → 自动匹配**:最近 N 站 + 推荐派遣 + 周边水源 + 匹配预案(一条警情串联所有)
- **派遣状态联动**:派遣后消防站图标标"出警中" + 路线高亮(状态回写)
- **2D ↔ 3D 联动**:态势总览点建筑 → 跳 `RealSceneView`(3D 建筑档案)— 圆环菜单加「3D 查看」
- **多面板同步**:态势选定目标 → 演练/预案面板带目标(已有 `gis:ignite-building` 事件雏形)

### 第 3 层:分析可视化 — 指挥决策辅助

- **响应圈**:每个消防站 5/10 分钟到达范围(等时圈多边形)— 识别**覆盖盲区**
- **风险热力图**:重点单位密度/风险等级热力(识别高风险聚集区)
- **蔓延模拟**:火势蔓延预测(风向 + 建筑结构 + 等级)— `TacticalOverlay` 现有 mock 蔓延圈,接真实模型
- **多路线对比**:派遣时多方案对比(ETA/距离/路况),推荐最优(已有 ETA,加"推荐"标注)

### 第 4 层:Agent 智能化 — 终极目标

**架构路径(MCP 驱动场景)**:
```
AgentChat(已有) ──→ Agent(智能体)
                        │ 调用 MCP 工具
                        ▼
                 MCP 服务端(新建,封装场景工具)
                        │ 工具:query_units / query_stations / plan_dispatch /
                        │       highlight / show_route / fly_to / search...
                        ▼
                 scene action 总线(扩展更多 action 渲染)
                        ▼
                 RealGisMap 渲染(地图响应)
```

**智能消防能力**:
- **AI 智能派遣**:警情 → agent 综合距离/车辆类型匹配(化工需泡沫车)/在位状态/路况 → 自动推荐派遣站 + 生成方案(调 `plan_dispatch` MCP)
- **自然语言指挥**:"庐山大道某化工厂着火" → agent 解析 → 定位 + 派遣 + 周边水源 + 匹配预案
- **智能问答**:"附近最危险的单位?""XX 站 5 分钟能到哪?"→ agent 查询 + 地图响应
- **预案匹配**:警情类型/建筑类型 → 自动匹配预案库 + 部署建议
- **风险评估报告**:agent 定期巡检重点单位 + 生成风险报告

## 三、优先级路线图(3 步)

> 排期原则:**数据先于智能、联动先于分析**。agent 要有数据才能决策。

### 🥇 第一步:警情/事件 + 自动联动(数据基础)
**价值**:让地图从"静态展示"变"动态指挥";为 agent 提供**警情/单位/水源数据基础**(agent 决策的前提)。
- 警情数据层(后端 incidents + 前端图层)
- 警情自动联动(选中警情 → 最近站 + 周边水源 + 派遣建议)
- 重点单位风险等级标注
- 消防站状态色

### 🥈 第二步:MCP 服务端 + AI 智能派遣(直奔 agent 核心)
**价值**:落地 agent 驱动场景的技术通道(用户重点)。
- 新建 `web/mcp-server`(FastMCP)
- `plan_dispatch` 工具(agent 智能选站 + 调 driving + 写 showRoute)
- 扩展 scene action 渲染通道(highlight/flyTo/addMarker 更多)
- AI 派遣算法(距离 + 车辆类型匹配 + 在位状态 + 路况综合评分)

### 🥉 第三步:自然语言指挥 + 智能问答
**价值**:降低使用门槛(对话即指挥)。
- AgentChat 接 MCP 工具
- 意图解析(自然语言 → 场景操作)
- 智能问答 + 预案匹配

### 后续(择机):分析可视化(响应圈/热力/蔓延)
独立于 agent,可随时插入(决策辅助)。

## 四、起步:第一步详细分解

### 4.1 警情数据层
- **后端 znya**:`incidents` 表(id/地址/类型/等级/经纬度/状态/时间/描述)+ crud_factory 路由 + seed mock 警情
- **前端 web**:`api/incidents.ts` + `incidents` 图层(红色脉冲点位 + 状态色)
- **MapLayerControl**:加「警情」图层 toggle

### 4.2 警情自动联动
- 点击警情 marker → 自动:
  - 算最近 N 消防站(haversine)
  - 标周边 X 米水源(filterByRadius)
  - 弹派遣面板(预填推荐站)
  - 显示警情信息(类型/等级/描述)
- 圆环菜单:警情(派遣/周边水源/详情)

### 4.3 重点单位风险等级
- key_units extra_attrs 加 `risk_level`(高/中/低 或 类型:高层/化工/人员密集)
- 图标/颜色区分(高风险红、中黄、低绿)

### 4.4 消防站状态色
- station.status 或从 fire_force_items 推断(出警 = 有 status=出警 的 item)
- 图标色:在位绿、出警橙、离线灰

### 建议第一个迭代(最小可用)
**警情图层(mock)+ 点击警情自动联动派遣**:用 mock 警情数据打通"警情→派遣"链路,验证联动价值,再接真实接警系统。

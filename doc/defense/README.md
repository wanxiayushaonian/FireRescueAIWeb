## 答辩主线建议（总—分—合）

1. **定位与痛点（1 分钟）**：预案"纸上谈兵"、演练组织成本高、指挥决策缺乏数据支撑 → 用真实建筑/预案/力量的数字化对抗演练验证预案韧性（01 §1）。
2. **总体架构（2 分钟）**：一张架构图讲清"平台托管 agent + 双 MCP 分工 + 浏览器执行 + 回执闭环"（01 §3，04 创新点 2/3）。
3. **深挖一个机制（3 分钟，最能体现开发深度）**：首推**对抗引擎**——四角色如何被程序编排、特情质量如何被程序门禁而不是靠模型自觉、人工决策如何闭环（02 §1）；备选**命令回执链**（02 §2）。
4. **现场演示（5–7 分钟）**：照 `DEMO.md` 脚本执行（黄金链 v2 已三连验收）。
5. **创新点收束 + Q&A（2 分钟）**：04 §1 八条按时间允许挑 3–4 条讲。

# 运行时提示词注入机制（前端代码侧）

> 源文件：`web/src/lib/agent-context.ts`、`web/lib/agent-evaluate.ts`、`web/src/drill/confrontation/confront-adapter.ts`。

## 1. 模块对话 `[系统上下文]` 前缀

前端状态（当前建筑/考核薄弱画像/选中警情等）在**每次发送消息时**以一行紧凑文本注入 content 前缀，不赌平台 `forwarded_props` 透传；前缀只进发送体，不进本地 messages（显示层不受影响）。各 agent 提示词统一按「界面状态，不要复述」处理。

格式（按模块与可用数据拼装，空段跳过）：

```text
[系统上下文|界面状态,非用户输入,不要复述] 3D场景=<sceneId>; 当前建筑id=<uuid>;
最近考核=战斗员/72分/总20题/错3题; 薄弱点位=避难层[13F]错3、室内消火栓[B1]错1;
低熟悉度=…; 当前警情=<id>/<type>/<status>; 地址=…; 坐标=<lng>,<lat>; 报警人=…
[/系统上下文]
<用户消息>
```

- objects 模块注入当前建筑 id（可直接喂 `query_building_profile`）。
- training 模块注入最近考核成绩、薄弱点位（错题画像前 5）、低熟悉度点位（<60% 前 3）；无考核记录时注入 `考核记录=无(用户尚未考核,可引导先做一轮)`。
- command 模块注入当前选中警情（id/type/status/地址/坐标/报警人）。
- 上下文是**快照**：熟悉度/成绩随用户操作变化，每次发送都会刷新。

## 2. 程序化消息前缀（对抗舱）

对抗舱按角色以固定前缀发程序化消息，提示词内与此一一对应：

| 前缀 | 角色 | 期望最终工具 |
|---|---|---|
| `[一级预案输出][preflight]` | Planner | `propose_initial_plan`（LLM 不产文本，以工具 JSON 参数交卷，schema 七必填强约束） |
| `[对抗开局]` | Planner | `report_decision`（初始部署基线） |
| `[导调触发]`（含 drill_id/round/当前态势/已用类型/最近事件与决策/拒绝原因） | Adversary | `inject_event` |
| `[指挥调整]`（含特情 + 当前态势 + 历史 + 人工基线段「人工已改派:…」） | Commander | `report_decision` |

> 整理注：四角色提示词源文件中这些前缀以 `\uXXXX` 转义形式存放（编辑器痕迹），本包已按运行时实际发送文本还原。

## 3. 评估消息模板与降级（`lib/agent-evaluate.ts`）

评估请求以消息前缀注入过程数据（演练预案评估 / 实战战后评估共用模板，60s 超时）：

```text
你是消防救援{预案评估|战后战评}专家。请根据给定的过程数据，完成客观、专业的评估。
只输出一个 JSON 对象，不要输出任何其他文字。JSON 结构：
{ "score": 0-100 整数, "conclusion": "一句话总评", "opinions": [...],
  "dimensions": [{"name","score","comment"}],
  "improvements": [{"content","target"}] }

评估对象：${subject}

过程数据：
${JSON.stringify(process)}
```

- 解析兼容 ```json fence、前后杂质文本、首尾花括号截取；字段缺失/非法返回 null。
- 任何失败（未配 app_id / 网络 / 超时 / JSON 解析失败）返回 null，调用方降级：**规则打分 `92 - ignored*8 - delayed*3`，UI 显式标注「降级评估 · 规则打分」**。
- 注意：对抗舱 Evaluator（见 prompts/confront-v2-evaluator.md）与该模板是两条链路——前者由对抗舱 finishEvaluate 传完整 timeline，后者供一级预案评估/战后评估复用评估 app。

## 4. 流式看门狗

`postAgentChat` 双层兜底：响应头 90s 超时（AbortSignal.timeout 与调用方 signal 经 AbortSignal.any 合成）+ 流空闲 90s 看门狗（chunk 到达即续期，无总时长上限，2-3min 长任务不受影响）。挂起以 `AgentStreamStalledError` 暴露，调用方 catch → 走既有降级路径（特情注入失败提示 / 规则打分）。
